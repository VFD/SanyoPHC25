# Livres pour le PHC-25


___
## Introduction

Aucun livre connu concernant le PHC-25.\
Cependant, écriture d'un volume reprenant les mots clef du BASIC avec plus d'explication.\
Un autre contenant des trucs de programmation BASIC.

Enfin, possibilité d'un autre sur le langage machine du PHC.\
Diverse technique pour mettre du LM dans les programmes.
